# Dominion of Sol — final visual acceptance captures

All captures were taken from the live Vite client against the live Rust server at 1280×720. The final set is:

- `01_world.png` — full world fit with terrain, political ownership, borders, labels, and capitals.
- `02_europe.png` — Europe and Mediterranean regional view.
- `03_turkey_close.png` — Turkey, Greece, Black Sea, and Caucasus vicinity.
- `04_himalaya.png` — Himalaya and Tibetan Plateau detail view.
- `05_andes.png` — Andes detail view.
- `06_japan.png` — Japan, Korea, and East China Sea detail view.
- `07_ocean.png` — ocean-heavy shelf and deep-basin view.
- `08_warfare.png` — real active attack presentation from faction 1 against faction 99, front 131.

The warfare capture uses an authoritative `isCombatActive: true` front payload. The arrow, engagement marker, and short visual hold are client presentation only; no simulation state is fabricated or prolonged.
